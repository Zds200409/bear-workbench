# 🐻 熊熊工作台 (Bear Workbench)

一个纯前端的个人效率管理工具，**单文件 HTML、零后端、手机可用**。所有数据保存在浏览器本地（`localStorage`），不依赖任何服务器。

## ✨ 功能模块

| 模块 | 说明 |
|------|------|
| 📅 今日计划 | 月历 + 当日固定行程（可点选日期查看） |
| 📕 小红书博主 | 虚拟资料店 + 好物分享博主，含文案/定价/标签 |
| 📨 公众号自动发布 | 内容生成 + 自动发布开关 |
| 🔥 每日热点新闻 | 热度排行 + 选题建议 + 多平台二创文案（刷新得最新题材） |
| 🔤 英语打卡 | 连续天数 + 上传打卡 + 历史记录 |
| 🍱 饮食·打卡 | 三餐 / 体重 / 打卡 |
| 📚 每日阅读 | 书籍管理 + 阅读进度 + 月度统计 |
| 📊 每周复盘 | 数据统计 + 亮点 / 改进 / 日记 |
| ⚙️ 设置 | 个人资料 / 提醒 / 数据导入导出 |

## 📦 本地运行

直接双击 `index.html` 即可在浏览器打开，无需任何安装。

## 📤 数据说明

- 所有打卡、计划、笔记都存在你自己的浏览器里（本地存储），**换设备/清缓存会丢失**。
- 「设置 → 数据导入导出」可备份 / 恢复全部数据。

## 🔧 技术栈

- 原生 HTML / CSS / JavaScript（单文件，约 68KB）
- 绿色主题，移动优先（手机底部导航栏 + 桌面侧边栏）
- 数据存储：`localStorage`（键名前缀 `bear_workbench_`）
