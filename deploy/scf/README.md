# 公众号自动发布 · 腾讯云 SCF 部署说明

替代 Cloudflare（国内访问太卡）。本函数**零依赖**，国内节点、不用加速器，调微信接口延迟低。

## 前置条件
1. 一个**已认证的服务号**（订阅号无发布 API 权限）。
2. 微信公众平台 → 设置与开发 → 基本配置 → 拿到 `AppID` 和 `AppSecret`。
3. 注册腾讯云账号（https://cloud.tencent.com ，实名一下，函数计算免费额度够用）。

## 第一步：创建函数
1. 腾讯云控制台 → **云函数 SCF** → **函数服务** → **新建**。
2. 创建方式：**自定义创建**；函数类型：**Web 函数**（或事件函数均可，本代码是 `main_handler`）。
3. 运行环境：**Node.js 18+**。
4. 函数代码：把本目录 `index.js` 的内容**整段粘贴**进 `index.js`（在线编辑器即可，无需 npm install）。
5. 在「**函数配置 → 环境变量**」里添加两条（密钥只存在云端，不进代码/仓库）：
   - `WECHAT_APPID` = 你的 AppID
   - `WECHAT_APPSECRET` = 你的 AppSecret
6. 保存。

## 第二步：开一个 HTTP 触发（给前端「🚀 推送到公众号」用）
1. 函数 → **触发管理** → **创建触发器** → 触发方式：**API 网关**（或 Web 函数自带访问路径）。
2. 记下生成的**访问路径 URL**（形如 `https://xxx.apigw.tencentcs.com/release/...`）。
3. 若用 API 网关，在网关控制台打开该服务的 **CORS**（允许 `*`），本函数也会回 `Access-Control-Allow-Origin: *`，双重保险。
4. 把这个 URL 填进工作台 App → **设置 → 自动发布设置 → 公众号发布地址(SCF)**。

## 第三步：开定时触发（让「定时发布」真正到点自动发）
1. 函数 → **触发管理** → **创建触发器** → 触发方式：**定时触发器**。
2. 触发周期选 **「每 15 分钟」**（Cron：`0 */15 * * * *`）。
3. 保存。函数每隔 15 分钟会扫一次微信草稿箱，把标题带 `【定时·HH:MM】` 且已到点的草稿自动提交发布并删除。

> 为什么是每 15 分钟而不是精确 09:30？因为精确时间要在控制台建很多定时器；每 15 分钟扫一次、到点即发，足够个人使用，且只用一个触发器。

## 用法对应
| App 里操作 | 实际发生 |
|---|---|
| 点「🚀 推送到公众号」 | 调 SCF `mode:'now'`：上传封面→写草稿→提交发布 |
| 开「自动发布开关」+ 设时间 + 有草稿 | 调 SCF `mode:'schedule'`：在微信草稿箱建一篇 `【定时·HH:MM】…` 草稿 |
| SCF 定时触发器每 15 分钟 | 扫描到点草稿 → 提交发布 → 删除该草稿 |

## 验证
- 先在 App 填好 SCF URL，点一次「🚀 推送到公众号」，公众号后台「发表记录」几分钟内出现即成功。
- 再试定时：开开关设个 1 分钟后的时间，等一个 15 分钟周期过去，看是否被自动发布。

## 排查
- 返回「未配置环境变量」→ 回函数配置补 `WECHAT_APPID/APPSECRET`。
- 返回权限错误（errcode 48001 等）→ 确认是**已认证服务号**，且 AppSecret 正确、未被重置。
- 前端报 CORS → 确认 API 网关已开 CORS，且 SCF URL 是 https。
- 定时没发 → 确认定时触发器已建且启用；草稿箱里能看到 `【定时·…】` 开头的草稿说明入队成功，只是还没到点/还没轮到 15 分钟扫描。
